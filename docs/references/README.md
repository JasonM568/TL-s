## 統計表速記（口徑：公司戶交換張數／金額）

- 114 年全年：3,295 萬張、10.06 兆元。
- 張數前三大行業：製造業 37%、批發零售 16%、營建工程 14%（合計約三分之二）。
- 平均每張：製造 16 萬、批發零售 17 萬、營建 23 萬、住宿餐飲 9 萬。
- 季節性：3、6、9、12 月為交換高峰；12 月金額全年最高（年關結算）。
- 趨勢：115 年 H1 張數年減 7.1%、金額年減 1.9%（緩降但結構穩定）。
- 引用注意：僅公司戶、不含個人戶；「不能歸類之行業」約佔 6%。
